# Lava Lamp

An interactive lava lamp with glowing wax, flowing internal detail, glass reflections, and thermal motion.

## Run locally

Open `index.html` in a modern browser. No installation or build step is required.

## Controls

- Choose a color using the color buttons.
- Adjust Heat to change the wax motion.
- Press Space to pause or resume.
- Press F to toggle fullscreen.

## Technology

Single-file HTML, CSS, JavaScript, WebGL / GLSL shaders, and a Canvas 2D fallback. No package dependencies or external assets are required.
